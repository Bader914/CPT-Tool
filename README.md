# CPT Tool

Een Streamlit-app voor het inlezen en visualiseren van CPT (Cone Penetration Test) data.

## Functionaliteiten

- Upload CPT bestanden (CSV, Excel)
- Interactieve grafieken met Plotly
- Kolommen selecteren voor visualisatie
- Data exporteren als CSV

## Lokaal draaien

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Online

Deze app is te bereiken via Streamlit Cloud.
